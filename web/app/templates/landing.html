Structured extraction

Printed text becomes named fields, then a consistency pass compares those fields with the MRZ so mismatches surface as data, not as guesses.

Three calls

Submit one image or PDF, poll from your backend, save the first finished response. No SDK required.

  1. Send one document image

    In a multipart POST /api/analyze, send the file as image and list the analyses in types, for example ocr,barcode.

  2. Poll from your backend

    Take the status_url from the 202 Accepted response. Poll it with GET, spacing out requests while the job is queued or running.

  3. Save the first completed response

    Use one poller per job. The first read of done or failed consumes the result. Check each section for an error, even when the job says done.

How we handle ID data

Where analysis runs and what the default self-hosted Docker setup keeps while handling an upload.

  • Built-in analyses

    When you self-host, OCR, MRZ, barcode, and face analysis run on your own CPU. No GPU or external inference service required.

  • Structured extraction

    The model receives OCR text, not images. BlitzID manages the model for the hosted API. If you self-host, you choose the model endpoint.

  • Hosted API

    Contact us about data residency and retention before sending production IDs.

Self-hosted data handling →

Self-hosted job lifecycle

  1. Queue in memory

    Redis holds the queued job with persistence turned off by default.

  2. Process and discard the upload

    When the job finishes, Redis removes the upload and keeps only the result.

  3. Read the result once

    The first fetch removes the result. If unread, it expires after 15 minutes by default.

Questions engineers ask

The short answers. The reference has the rest.

Which documents are supported?

Passports, national ID cards, and driver's licenses, including US and Canadian licenses with PDF417 barcodes. The OCR pass is not limited to a document list: if text can be read and an MRZ or barcode is present, fields can be extracted.

Can I try it before paying?

There's no free hosted plan, but you can run the open-source API locally without an account. The self-hosted API has no built-in auth; put it behind your own auth proxy if you expose it.

Does a valid MRZ prove the ID is genuine?

No. A valid MRZ or barcode proves the document is readable and internally consistent. Genuine-document checks need policies, issuing authority data, or vendor-specific security features. BlitzID gives you signals; your code makes the decision.

How long does analysis take?

OCR and MRZ each took about one second per specimen image in a warm laptop CPU benchmark. Hosted latency also depends on upload time, queue time, and the analyses you request.

What errors should I retry?

Retry 503 after the Retry-After delay; the queue is full or briefly unavailable. Don't retry 410: that result was already read or has expired. See the error handling guide for the rest.

How do I authenticate hosted requests?

Create an API key in the dashboard and send Authorization: Bearer <key>. Self-hosted deployments have no built-in auth; put them behind your own auth proxy.

What happens when I hit a rate limit or quota?

Requests over the per-minute rate get 429 with a Retry-After header. When the monthly quota is used, the dashboard shows it and API calls are rejected until the next period or an upgrade.

Can my company get an invoice?

Enter your company details at checkout, then download your subscription invoices from Manage billing in the dashboard. For purchase orders or payment terms, contact sales.
